\section{Онолын болон харьцуулсан судалгаа}
\label{sec:literature-review}

Энэ бүлэгт Монгол бичгийн түүх, flashcard сургалтын систем, орчин үеийн гар утасны аппликейшн хөгжүүлэлтийн технологиуд, мөн ижил төстэй хэл сурах аппликейшнуудын талаарх онолын судалгааг дэлгэрэнгүй авч үзнэ.

\subsection{Монгол бичгийн түүх ба онцлог}
\label{subsec:mongolian-script}

Монгол бичиг нь XIII зуунаас төр, соёл, боловсролын хэрэглээнд хөгжсөн уламжлалт босоо бичгийн систем бөгөөд орчин үед дахин хэрэглээг нэмэгдүүлэх бодлогын хүрээнд сургалтын чанартай дижитал хэрэглүүрийн хэрэгцээ нэмэгдэж байна. Иймээс уг бичгийг сурахад тулгардаг хэлбэр-зүйн хүндрэлүүдийг технологийн аргаар хөнгөвчлөх нь энэхүү ТСА-ийн суурь үндэслэл болно.

Бүтцийн хувьд Монгол бичиг нь дээрээс доош бичигддэг, үсэг нь үгийн эх, дунд, адагт өөр хэлбэрээр хувирдаг, мөн холбоо бичлэгийн дүрмээр онцлогтой. Энэ онцлогоос шалтгаалан суралцагчид үсгийн байрлал, холбоосын дүрэм, дуудлага-утгын хамаарлыг зэрэг эзэмших шаардлагатай болдог тул flashcard болон OCR дэмжлэгтэй сургалтын орчин зайлшгүй хэрэгтэй.

\subsection{Мэдлэг эзэмших танин мэдэхүйн аргууд: Spaced Repetition болон Flashcard}
\label{subsec:flashcard-systems}
Flashcard арга нь \textit{active recall} буюу идэвхтэй санах ойг өдөөх замаар үсэг, үгийн тогтоцыг сайжруулдаг бөгөөд хэл суралцахад өндөр үр дүнтэй болох нь судалгаагаар батлагдсан~\cite{karpicke2008critical}. Мөн марталтын муруйн онолд тулгуурлан давталтыг зөв хугацаанд хийх нь мэдээллийг урт хугацааны санамжид илүү тогтвортой хадгалахад чухал нөлөөтэй~\cite{ebbinghaus1985memory}.

Spaced repetition-ийн практик хэрэгжилт болох SM-2 алгоритм нь хэрэглэгчийн өмнөх хариултын чанарт тулгуурлан дараагийн давталтын хугацааг динамикаар тооцоолдог~\cite{wozniak1990optimization}. Иймээс Egüü системд flashcard сургалтыг SM-2 логиктой нэгтгэснээр Монгол бичгийн үсэг, үгсийг шаталсан давтамжаар илүү үр дүнтэй эзэмших боломж бүрдүүлсэн.

\subsubsection{SM-2 алгоритмын математик томьёолол}

SM-2 алгоритмд карт бүрийн төлөвийг $(I_n, EF_n, q_n)$ гэж тэмдэглэнэ. Энд
$I_n$ нь давталтын интервал (repetition interval),
$EF_n$ нь хялбаршлын коэффициент (easiness factor),
$q_n$ нь тухайн оролдлогын үнэлгээ ($0$–$5$ онооны систем) юм.

\begin{equation}
I_1 = 1, \qquad I_2 = 6, \qquad I_n = I_{n-1} \cdot EF_{n-1} \; (n \ge 3)
\end{equation}

\begin{equation}
EF_n = EF_{n-1} + \left(0.1 - (5-q_n)\left(0.08 + (5-q_n)\cdot 0.02\right)\right),
\end{equation}

энд $q_n \in \{0,1,2,3,4,5\}$ нь тухайн оролдлогын үнэлгээ бөгөөд $EF_n \ge 1.3$ хязгаарлалтыг баримтална. Хэрэв $q_n < 3$ бол картын давталтыг дахин эхлүүлж, дараагийн интервал $I_1$-ээс тооцогдоно.

\subsection{Гар утасны аппликейшн хөгжүүлэлтийн технологиуд}
\label{subsec:mobile-technologies}

\subsubsection{React Native - Cross-Platform фреймворк}

Энэхүү ТСА-д React Native-г сонгосон гол шалтгаан нь нэг кодын сангаар iOS болон Android-д зэрэг ажиллах боломж юм~\cite{nack2016learning}. Egüü системийн UI дэлгэцүүд, навигаци, компонентын архитектур нь React Native (Expo)-д суурилан хэрэгжсэн бөгөөд хөгжүүлэлтийн хугацаа болон засвар үйлчилгээний зардлыг бууруулахад үр дүнтэй байсан.

\subsubsection{Firebase - Backend-as-a-Service}

Firebase нь энэ ТСА-д backend дэд бүтэц болгон ашиглагдсан бөгөөд Authentication, Cloud Firestore, Cloud Storage үйлчилгээг нэг платформоос шийдсэн~\cite{welekar2017firebase}. Serverless модель ашигласнаар тусдаа серверийн удирдлага шаардалгүйгээр хэрэглэгчийн өгөгдөл хадгалах, синхрончлох, хандалтын эрхийг Security Rules-ээр хянах боломж бүрдсэн.

\subsection{TensorFlow.js ба OCR технологи}
\label{subsec:tensorflow-ocr}

TensorFlow.js нь JavaScript орчинд машин сургалтын модель ажиллуулах боломж олгодог тул Egüü системийн OCR функцийг гар утсан дээр client-side inference хэлбэрээр хэрэгжүүлэхэд ашигласан~\cite{smilkov2019tensorflow}. Энэ шийдэл нь хэрэглэгчийн зураг, бичвэрийн өгөгдлийг төхөөрөмжөөс гадагш дамжуулахгүй байх, мөн сүлжээ сул үед ч танилтын үндсэн үйлдлийг үргэлжлүүлэх давуу талтай.

ТСА-д OCR нь зураг авах/оруулалт, урьдчилсан боловсруулалт, моделээр ангилалт, үр дүнг текст болгон харуулах гэсэн үндсэн үе шаттайгаар хэрэгжсэн. Ингэснээр Монгол бичгийн гар бичмэлийг шууд таних туршлагыг flashcard сургалттай холбож, хэрэглээний бодит үнэ цэнийг нэмэгдүүлсэн.

\subsubsection{OCR сургалтын зорилтот функц (CTC)}

OCR загварын сургалт нь оролтын дараалал $x$ болон зорилтот тэмдэгтийн мөр $y$-ийн хооронд CTC (Connectionist Temporal Classification) алдагдлыг багасгах зорилготой:

\begin{equation}
\mathcal{L}_{CTC} = -\log P(y|x) = -\log \sum_{\pi \in \mathcal{B}^{-1}(y)} P(\pi|x),
\end{equation}

энд $\pi$ нь blank-тэй өргөтгөсөн alignment дараалал, $\mathcal{B}$ нь олон цагийн алхмыг нэгтгэн эцсийн тэмдэгтийн мөр үүсгэх collapse оператор юм. Энэ нь тэмдэгт бүрийн байршлыг таних боломж олгодог.

\subsection{Ижил төстэй аппликейшнуудын харьцуулсан судалгаа}
\label{subsec:comparative-analysis}

Хэл сурах аппликейшнуудаас Duolingo (gamification, 500 сая+ хэрэглэгч), Anki (SM-2 алгоритм), Memrise (видео) гэх мэтүүд тэргүүлэгчүүд юм. Монгол хэлний орчинд Bolor Toli~\cite{bolor-toli}, Tungaamal Toli~\cite{tungaamal-toli} зэрэг шийдлүүд хэрэглэгддэг боловч эдгээр нь үндсэндээ толь/орчуулга, дуу авиа болон хөрвүүлэлтийн зориулалттай. \textit{Судалгаанд хамруулсан (reviewed) аппликейшнуудын хүрээнд} OCR-оор гар бичвэр танилтыг flashcard болон spaced repetition сургалтын аргатай нэгтгэсэн мобайл систем тодорхой ажиглагдаагүй тул энэ цоорхойг нөхөхөөр Egüü төслийг хөгжүүлсэн.

\subsubsection{Egüü ТСА давуу талууд}

Дээрх судалгааны үндсэн дээр Egüü ТСА нь дараах давуу талуудтай:

\begin{enumerate}
    \item \textbf{Монгол бичигт тусгайлсан:} Толь/орчуулгын чиглэлийн аппликейшнүүд (жишээ нь: Bolor Toli, Tungaamal Toli)~\cite{bolor-toli,tungaamal-toli} байгаа ч Egüü нь Монгол бичгийн сургалтыг flashcard, spaced repetition, OCR урсгалтай нэг дор нэгтгэснээр ялгарна.
    
    \item \textbf{OCR технологи:} Хэрэглэгч гараар бичсэн үгээ таниулах боломжтой. \textit{Судалгаанд хамруулсан (reviewed) аппликейшнуудын хүрээнд} ижил түвшний OCR + сургалтын нэгдсэн урсгал ажиглагдаагүй.
    
    \item \textbf{Орчин үеийн UI/UX:} React Native, NativeWind ашиглан орчин үеийн, сонирхолтой интерфэйс бүтээсэн.
    
    \item \textbf{Gamification + Spaced Repetition:} Duolingo-ийн gamification болон Anki-ийн spaced repetition-ийг хослуулсан.
    
    \item \textbf{Олон хэлний дэмжлэг:} i18n ашиглан Монгол, Англи хэлээр ашиглах боломжтой.
    
    \item \textbf{Үнэгүй, нээлттэй эх:} Бүх хүнд хүртээмжтэй бөгөөд нийгэмд хувь нэмэр оруулах боломжтой.
\end{enumerate}

\subsection{Бүлгийн дүгнэлт}

Энэхүү бүлгийн онолын болон харьцуулсан судалгаагаар Egüü системд ашигласан гол суурь шийдлүүдийг тодорхойлов. Монгол бичгийн сургалтын онцлогт нийцсэн flashcard, SM-2 аргачлал, React Native, Firebase мөн TensorFlow.js-д суурилсан OCR хэрэгжилт юм. Иймээс дараагийн бүлэгт эдгээр суурь дүгнэлтэд тулгуурлан системийн шинжилгээ, архитектурын зохиомжийг логик дарааллаар танилцуулна.
