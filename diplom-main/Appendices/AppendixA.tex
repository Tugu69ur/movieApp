\subsection*{А.2 Firestore Database Schema}

Egüü системд ашигласан Cloud Firestore-ийн өгөгдлийн бүтэц:

\begin{lstlisting}[language=JavaScript, caption=Flashcards collection-ийн бүтэц, label={lst:flashcards-structure}]
flashcards/
  {flashcardId}/
    - mongolBichig: string          // Монгол үсэг
    - phonetic: string
    - english: string
    - definition: string
    - imageUrl: string
    - category: string              // "vowels" | "consonants"
    - difficulty: number             // 1-5
    - createdAt: Timestamp
\end{lstlisting}

  Энэхүү List нь flashcard бүрийн үндсэн талбаруудыг (үсэг, орчуулга, категори, хүндрэл, үүсгэсэн огноо) хэрхэн хадгалж байгааг харуулна.

\begin{lstlisting}[language=JavaScript, caption=Users collection-ийн бүтэц, label={lst:users-structure}]
users/{userId}/
    - email, displayName, photoURL
    - preferences: {language, theme, notifications}
    - stats: {totalStudied, currentStreak, longestStreak, lastStudyDate}
\end{lstlisting}

  Энэ List нь хэрэглэгчийн профайл, тохиргоо болон суралцах статистикийг нэг баримт дээр нэгтгэн хадгалах логикийг илэрхийлнэ.

\begin{lstlisting}[language=JavaScript, caption=UserProgress collection-ийн бүтэц, label={lst:userprogress-structure}]
userProgress/{userId}/flashcards/{flashcardId}/
    - easinessFactor: number        // SM-2 parameter (1.3-2.5)
    - interval: number              // Days until next review
    - repetition: number
    - nextReviewDate, lastReviewDate: Timestamp
    - reviewHistory: [{date, quality}]
\end{lstlisting}

  Энэхүү List нь SM-2 алгоритмын хувьсагчид болон дараагийн давталтын огноог хэрэглэгчийн түвшинд хэрхэн хадгалдгийг харуулна.

\begin{lstlisting}[language=JavaScript, caption=Favorites болон DailyWords collection-ийн бүтэц, label={lst:favorites-dailywords}]
favorites/{userId}/
    - flashcards: array<string>
    - addedAt: map<string, Timestamp>
    
dailyWords/{date}/
    - flashcardId: string
    - createdAt: Timestamp
\end{lstlisting}

Энэ List нь хэрэглэгчийн дуртай жагсаалт болон өдрийн үгийн санамсаргүй сонголтын өгөгдлийн бүтцийг товчлон үзүүлнэ.

\subsection*{А.3 Firebase Security Rules}

Egüü системд ашигласан Firebase Security Rules-ийн бүрэн код:

\begin{lstlisting}[language=JavaScript, caption=Firestore security rules-ийн код, label={lst:firestore-rules}]
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Flashcards collection - бүх хүн унших боломжтой
    match /flashcards/{flashcardId} {
      allow read: if true;
      allow write: if request.auth != null && 
                      request.auth.token.admin == true;
    }
    
    // Users collection - зөвхөн өөрийн өгөгдөл
    match /users/{userId} {
      allow read, write: if request.auth != null && 
                            request.auth.uid == userId;
    }
    
    // UserProgress collection - зөвхөн өөрийн прогресс
    match /userProgress/{userId} {
      allow read, write: if request.auth != null && 
                            request.auth.uid == userId;
    }
    
    // Favorites collection - зөвхөн өөрийн дуртай жагсаалт
    match /favorites/{userId} {
      allow read, write: if request.auth != null && 
                            request.auth.uid == userId;
    }
    
    // DailyWords collection - бүх хүн унших боломжтой
    match /dailyWords/{date} {
      allow read: if true;
      allow write: if request.auth != null && 
                      request.auth.token.admin == true;
    }
  }
}
\end{lstlisting}

Энэхүү List нь өгөгдөлд хандах эрхийн түвшинг collection бүрээр ялгаж, зөвхөн тухайн хэрэглэгч өөрийн мэдээлэлд хандах хамгаалалтын зарчмыг хэрэгжүүлж байгааг харуулна.

\begin{lstlisting}[language=JavaScript, caption=SM-2 алгоритмын үндсэн томъёо]
// Update Easiness Factor
EF' = EF + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))

// Calculate next interval
if (quality < 3) {
  interval = 1;  // Repeat again
} else {
  interval = repetition === 0 ? 1 : repetition === 1 ? 6 : Math.round(interval * EF);
}
\end{lstlisting}

Энэ Listийн утга нь хэрэглэгчийн үнэлгээнээс хамаарч давталтын зайг динамикаар тооцох SM-2 алгоритмын цөм логикийг харуулахад оршино.

\begin{lstlisting}[language=JavaScript, caption=utils/streakTracker.ts]
export const updateStreak = (lastStudyDate: Date | null): {
  currentStreak: number;
  shouldReset: boolean;
} => {
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  
  if (!lastStudyDate) return { currentStreak: 1, shouldReset: false };
  
  const lastDate = new Date(lastStudyDate);
  lastDate.setHours(0, 0, 0, 0);
  const diffDays = Math.floor((today.getTime() - lastDate.getTime()) / (1000 * 60 * 60 * 24));
  
  if (diffDays === 0) return { currentStreak: 0, shouldReset: false };
  if (diffDays === 1) return { currentStreak: 1, shouldReset: false };
  return { currentStreak: 1, shouldReset: true };
};
\end{lstlisting}

Энэхүү List нь хэрэглэгчийн сүүлийн суралцсан өдрөөс хамаарч streak-ийг хадгалах эсвэл reset хийх дүрмийг кодын түвшинд тайлбарлаж байна.
